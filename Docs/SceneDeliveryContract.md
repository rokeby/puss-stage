# Scene delivery contract

The rules every Scene must satisfy to drop into the Infinity Stage Show without
hand-fixing. Applies to scenes built in-house and to any outsourced scene — send
this file with every brief.

Task **I.8**. Companion: [creative checklist](ShowCreativeTodo.md).

## Format

| | |
| --- | --- |
| Deliverable | One Unreal **Level Sequence** asset, in the project |
| Engine | Unreal Engine **5.8** |
| Display rate | **25 fps** |
| Tick resolution | **24000** |
| Naming | `LS_<SceneName>` — do not rename after delivery; the Show references it |

Frame rate is not negotiable. The Master owns one clock, and a sequence authored
at another rate resolves to fractional frames at every boundary.

## The camera rule that actually breaks things

**The Camera Cut track must sit at the top level of the delivered sequence.**

The Show claims a Scene's camera by reading the sequence's top-level Camera Cut
track. A cut placed inside a Shots subsequence is *never claimed*, and the
symptom is not an error — the Scene plays with the previous Passage's camera
still live, which reads as "the scene didn't happen".

A subsequence that *animates* the bound camera is fine and often correct. The
claim only cares where the **cut** lives, not where the animation lives.

## Entry and exit

A Scene is handed the camera by the Passage before it and hands it back to the
Passage after it.

- **First frame** matches the incoming Passage endpoint — transform, lens, focus.
- **Last shot** is reserved for the handback: `ExitHandoffHoldFrames` at the end
  of the Scene holds a camera matched to the next Passage's start.
- Both cameras are generated by **Actions → Scene Camera Handoff → Match
  Selected Scene**. Run it after delivery, and again after any route or lens
  change upstream.

Handoff cameras are a **snapshot**, not a live link. Change a Passage route or a
focal-length key afterwards and they go stale, producing a visible jump. **Check
All Scenes** reports which ones no longer match; run it before every rehearsal.

Internal artist-authored cuts between the entry and exit shots are preserved.
Cut freely in the middle; just leave the first and last shots alone.

## Duration

- Lock the Scene's length against its **audio stem** before animating.
- Set **`bUseSequenceLength`** on the cue so the Show takes its length from the
  sequence. Do not also maintain a hand-typed `DurationFrames` — a second number
  that must be kept in step is the stale-snapshot trap this system exists to avoid.
- Changing length after delivery re-times the Master and re-fits neighbours.
  Treat it as a structural change, not a tweak.

## Things that belong inside the Scene, not on the Master

The managed Master sequence is **rebuilt** whenever cue order, timing or duration
changes, and artist-authored tracks on it are not preserved.

- **Surtitles** — bind `BP_Surtitle` inside the Scene sequence and key it with a
  native Text track. It then retimes with the Scene for free.
- **Scene audio** — on the Scene, bound through the cue's music binding.
- **Lighting** — ordinary level and sequence lighting inside the Scene's own bay.

## Camera ownership

Declared per Scene in the Show, not by the animator, but it changes what you
should author:

- **Timeline** — you author camera motion normally.
- **Dog / Dog Gaze Only** — the live operator drives orientation. **Do not key
  camera rotation**, or two systems write the same value and fight. A static base
  orientation to look around from is acceptable if it is a deliberate decision;
  `Check All Scenes` will flag it either way so it gets looked at.

## Checklist before a Scene is accepted

- [ ] Level Sequence, 25 fps, tick resolution 24000
- [ ] Camera Cut track at top level
- [ ] First frame matches incoming Passage endpoint
- [ ] Handback shot reserved at the end
- [ ] Length locked against the audio stem; `bUseSequenceLength` set
- [ ] No keyed camera rotation if the dog owns the camera
- [ ] Surtitles bound inside the sequence, not the Master
- [ ] `Match Selected Scene` run, then `Check All Scenes` clean
- [ ] Plays through both boundaries with `Play Through Boundaries` on
