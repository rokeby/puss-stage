## 1. Transient editor auto-hide

`Scripts/Unreal/p18_editor_sky_autohide.py` hides SkyLight, SkyAtmosphere,
VolumetricCloud, sky-sphere classes and DirectionalLights outside the persistent
map, leaving the persistent P06 sun alone **[declaration-proven:
`Scripts/Unreal/p18_editor_sky_autohide.py:46-64`]**. It uses only
`set_is_temporarily_hidden_in_editor`, reads that transient state back, compares
the exact dirty census before/after, and ignores PIE **[declaration-proven:
`Scripts/Unreal/p18_editor_sky_autohide.py:87-128`]**.

UE 5.8 declares Python-visible dynamic `OnMapChanged` and `OnMapOpened`
delegates, plus the subsystem's level-added/removed handler
**[declaration-proven:
`D:/Unreal Engine/UE_5.8/Engine/Source/Editor/LevelEditor/Public/LevelEditorSubsystem.h:28-31,251-262`]**.
The module registers both delegates and also watches the loaded-level package
set every 0.5 s, so an on-demand streamed-level load queues a deferred pass
even if MapChanged is early **[declaration-proven:
`Scripts/Unreal/p18_editor_sky_autohide.py:149-212`]**. Live UE firing remains
unmeasured until the conductor applies the held patch and restarts the editor
**[inferred: offline harness cannot exercise UE delegates]**.

The off switches are `PUSS_EDITOR_SKY_AUTOHIDE=0` or
`Saved/CodexConductor/disable_p18_sky_autohide.flag`
**[declaration-proven: `Scripts/Unreal/p18_editor_sky_autohide.py:26-43`]**.
